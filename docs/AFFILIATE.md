# アフィリエイト運用ルール

アフィリエイト(A8.net / afb 等)のリンクを載せる作業では、この文書を先に読む。
広告主の条件は変わるため、**掲載の直前に各プログラムの詳細ページで再確認する**こと。

## 共通ルール

- 広告とわかる表示(「PR」「広告」)を、**ページの最初に見える位置**に置く。リンク横だけでは不足
- 素材リンク(トラッキングURL)は発行されたものをそのまま使う。改変禁止
- 自分で自分のリンクから申し込んで報酬を得る行為(自己アフィリエイト)は原則禁止
- 広告主が提供するPR文・セールスポイントを**転載しない**(薬の名前・価格・割引が含まれ、広告に適さない場合がある)
- 報酬だけで掲載順位・推奨順位を決めない(`CLAUDE.md` 12章)
- 広告を載せたページの公開後、A8.netの「広告掲載URL管理」からURLを提出する
- GA4へは既存の承認済みイベントのみ。個人情報・スコア・相談本文は送らない
- 置き場所は、プログラムの対象読者に合うページに限る。対象外の層に向くページ(欲求MAPの結果、一般記事)には置かない

## 医療系(オンライン診療など)

- 薬の名称、価格、割引、効果の断定、体験談、比較・ランキング形式の表現は使わない
- 紹介は「医療機関に相談する選択肢の一つ」にとどめ、購入を急がせる表現は避ける
- 迷う表現は、広告主の掲載ルールと医療広告ガイドラインを優先し、必要なら専門家に確認する

## CIの安全チェック(`scripts/quality-check.mjs`)

広告リンク(`px.a8.net`)があるページは、次を満たさないとビルドが失敗する。

- 承認済みの記事ページだけにある(許可リストは、このスクリプト内の `AFFILIATE_ALLOWED_PAGES`)
- ページの `<h1>` より前に PR 表示(`class="pr-notice"`)がある
- リンクに `rel="sponsored"` がある
- サンプル・仮の値(`a8mat=TEST` など)や `REPLACE_WITH_` が残っていない

新しいプログラムや記事に広告を置くときは、許可リストにも追記する(データ側とCI側の両方が揃わないと載らない二重の鍵)。
