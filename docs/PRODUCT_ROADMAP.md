# INTIMETRY Product & Revenue Roadmap

## North Star
性生活を、もっと豊かに。

INTIMETRYは「性格診断サイト」ではなく、自分の欲求を知り、言いにくい悩みを相談し、相手との違いを理解し、自分に合う選択肢へつながる Sexual Wellbeing Platform を目指す。

## Phase 1 — MVP
公開するのは次の2本だけ。

### MAP
- 24問の欲求MAP
- Preference と NOW を分離
- 回答値・個別スコアはブラウザ内処理
- GA4は開始、完了、シェア、導線クリックのみ

### TALK
- 18歳以上向け匿名相談
- セックスレス、性欲差、マンネリ、誘い方、性的な好み等
- ニックネーム・返信メールは任意
- 診断データと相談本文を紐付けない
- 本人の明示同意がある相談だけ匿名化・編集後にコンテンツ化

## Phase 2 — PAIR
- パートナー招待
- 二人のMAP比較
- GAP TRANSLATOR
- 「相性の良し悪し」ではなく差分と会話方法を提示
- サーバー保存前に保存期間、削除方法、暗号化、アクセス制御を設計

## Phase 3 — INTIMETRY+
- 詳細レポート
- 再診断・HISTORY
- 二人向け会話テーマ
- AI会話サポート
- プレミアムコンテンツ
- 月額/年額課金を検証

## Phase 4 — GUIDE / COMMERCE
- MAPに応じた記事・体験・商品・サービスの提案
- アフィリエイトから開始
- 需要が確認できたカテゴリだけ卸・自社商品へ
- 広告・PRは明瞭に表示し、報酬だけで推奨順位を決めない

## Phase 5 — PRO / API
### INTIMETRY PRO
専門家向けSaaS。
- クライアントMAP
- ペア差分
- 経時変化
- 相談前ヒアリング補助

### INTIMETRY API
- assessment
- scoring
- compatibility
- white-label
- 婚活・結婚相談所・ウェルネス事業者等への提供

## Phase 6 — INDEX
匿名・集計データを用いた独自調査。
- 年代別欲求差
- 交際年数とマンネリ
- 性欲差
- 親密性
- 言いづらい悩み

個人データを販売しない。調査同意、匿名化、集計単位、再識別防止を前提にする。

## Phase 7 — MATCH
実ユーザー同士のマッチングは最後。
- 顔・スペック中心ではなく、価値観・親密性・欲求の適合を重視
- Similarity + Complementarity の両方で設計
- NOWの一時的状態は恒常的な相性スコアに混ぜない
- 実装前にインターネット異性紹介事業等の該当性、届出、年齢確認、安全対策を専門家と確認

## MVP KPI
- 欲求MAP開始率
- 完了率
- 結果シェア率
- 匿名相談送信率
- 記事/相談への回遊率
- レコメンドCTR
- 再訪率

初期の成功判定は「PV」ではなく、診断完了・相談発生・再訪・収益導線の反応で行う。

## 撤退 / 方向転換条件
30日〜60日の検証で以下がすべて弱い場合は、機能追加を止める。
- 診断完了率が改善しても低い
- 匿名相談がほぼ発生しない
- シェア・再訪が弱い
- 商品/サービス導線への反応がない

その場合は、診断テーマ、対象ユーザー、入口SNSを見直す。
